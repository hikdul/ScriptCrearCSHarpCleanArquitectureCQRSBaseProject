# Agent Runs

This directory is for optional per-run evidence produced by the development
agents: the specification used, the commands executed, the test counts
(passed / failed / skipped), the files changed, and any open questions.

A run record is evidence, not a summary. Keep it short and objective.

Rules:

- Never claim a command passed without including its observed output or counts.
- Record skipped tests explicitly; a run with skips is not a fully validated run.
- Do not record secrets, connection strings or credentials.
- This directory is not a substitute for the specification or the commit history.

The directory is intentionally empty at bootstrap.
